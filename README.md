**Nombre de proyecto asignado**: Control de espacios de estacionamiento

**Descripción**:
Este sistema implementa un control de estacionamiento utilizando dos patrones de diseño fundamentales. El **patrón Singleton** garantiza que exista un único controlador central que gestiona todo el estacionamiento, asegurando consistencia en los datos y evitando múltiples instancias. Simultáneamente, el **patrón Object Pool** administra los espacios de parking creándolos una vez al inicio y reutilizándolos eficientemente, donde cada espacio alterna entre estados "Disponible" y "Ocupado". La integración de ambos patrones permite un sistema robusto donde los espacios se reciclan constantemente bajo la supervisión de un controlador único, optimizando recursos y manteniendo un funcionamiento ordenado y escalable.
